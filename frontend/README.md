# documind Frontend

Lokale React-basierte Benutzeroberfläche für die PDF AI App.

## Geplante Features

- PDF Upload
- Text Extraktion Anzeige
- Chat-Interface mit PDFs
- Versionierung mit Tauri (später)

## Tech Stack

- React 18+
- TypeScript
- Vite (Build Tool)
- Tauri (Desktop, später)
