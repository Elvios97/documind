# Screenshot-Notizen

Dieser Ordner ist fuer Projekt-Screenshots vorgesehen.

Empfohlene Motive:

- Desktop-App mit hochgeladenem PDF, Antwort und Quellen
- Dokumentenliste mit aktivem Dokument
- Quellenbereich mit Seitenbezug und Chunk-ID
- Optional: Backend-Status online und lokale Datenschutz-Hinweise

Vor dem Screenshot:

1. Backend starten.
2. Frontend oder Tauri-App starten.
3. Beispiel-PDF hochladen.
4. RAG-Frage stellen.
5. Fensterbreite so waehlen, dass Sidebar, Antwort und Quellen sichtbar sind.
